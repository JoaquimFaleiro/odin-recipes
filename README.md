# Odin Recipes

## Description
This project is a recipe website developed as part of The Odin Project's Foundations curriculum.
The primary objective is to build a functional multi-page website from scratch, demonstrating core web development concepts.

## Skills Demonstrated
Upon completion of this project, the following competencies will be demonstrated:
* **HTML Structure:** Correct use of headings, paragraphs, links, images, and lists.
* **Git & GitHub Workflow:** Repository initialization, committing changes with descriptive messages, and pushing to a remote repository.
* **CSS Fundamentals:** Structuring layouts, managing typography, and applying basic styling to enhance user experience.
* **File Management:** Organizing project directory structures with relative paths.
